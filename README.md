#Repositorio de Programacion Orientada a Objetos



##1. Crear .gitignore

Crear el archivo .gitinogre para configurar los archivos y capetas que se guarden en el repositorio.

````shell
*.pyc
_pycache_/
````

## 2. Indexar archivos y carpetas 

Indexa todos los directorios y carpetas en busca de documentos nuevos.

````shell
git add .
````

## 3. Crear un COMMIT

Crea un commit o punto de control de los cambios realizados en el proyecto.

````shell
git commit -m "CREATED .gitignore"
````

*CREATED - Se crearon nuevas carpetas o archivos.
*UPDATED- Se actualizaron o agregaron nuevas funciones 
*FIXED - Se corrigieron nuevos errores.


## 4. Realizar el COMMIT

Sincoroniza los ca,bios realizados en el repositorio.

````shell
git push -u origin main
````
